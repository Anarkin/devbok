Angular · cheatsheet · version 1 · 2026-09-08

Angular

cheatsheet · Angular 22.1.5 · released 2026-09-03

The Angular surface reached for daily — component and template syntax, signals, DI, the resource and HTTP APIs, Signal Forms, the router, SSR and the CLI — each row labelled with the version where it became true, plus a modern-vs-legacy table and a timeline. It reflects the v22 line: v22.0.0 GA on 2026-06-03, current patch 22.1.5 on 2026-09-03, with Signal Forms, Angular Aria and the async reactivity APIs stable and OnPush now the default change-detection strategy. "Angular" here is the framework from v2 onwards (angular.dev), not AngularJS 1.x, which has been out of support since 2022.

01Component & template syntax

docs: templates
Component
@Component({ selector: 'app-cart', imports: [CartRow], template: `…` }) — standalone is implicit since v19; only standalone: false is still written, for NgModule leftovers. Change detection defaults to OnPush v22; the old always-check mode is ChangeDetectionStrategy.Eager
Selectorless use
import { CartRow } from './cart-row'; then <CartRow [item]="row()" /> v22 — the class name is the tag, a missing import is a compile error instead of an unmatched element
Selectorless directive
<input @Tooltip="'Search'" /> v22 — stack several; inputs bind as [x] on the same element
Interpolation / property / event
{{ total() }} · [disabled]="busy()" · (click)="add(item)" · attribute [attr.aria-label] · class [class.on] · style [style.width.px]
Two-way
<app-qty [(value)]="qty" /> — pairs with model() in the child; works with a plain signal on the parent side
Conditionals
@if (user(); as u) { {{ u.name }} } @else if (loading()) { … } @else { … } v17
Loops
@for (row of rows(); track row.id) { … } @empty { Nothing } — track is mandatory; $index $count $first $last $even $odd are in scope
Switch
@switch (state()) { @case ('a', 'b') { … } @default { … } } — multi-value cases and never exhaustiveness checks v22
Template variable
@let full = user().first + ' ' + user().last; v18.1 — read-only, scoped to the block
Lazy block
@defer (on viewport; prefetch on idle) { <Chart /> } @placeholder { … } @loading (after 100ms) { … } @error { … } v17
Error boundary
@boundary { … } @error (e) { … } v22, experimental — contains a render error instead of tearing down the app
Spread & arrow fns
[class]="{ ...base, active: on() }" · (click)="pick((x) => x.id === id)" v22
Comment inside a tag
<input [value]="v" /* (blur)="save()" disabled for now */ /> v22
Projection
<ng-content select="[header]" />, fallback content between the tags v18; <ng-template> + <ng-container> for structural work
Host bindings
host: { '[class.open]': 'open()', '(keydown.escape)': 'close()' } in the decorator — the style guide prefers this over @HostBinding/@HostListener v20
File naming
cart.ts / cart.html / cart.css and class Cart v20 style guide — the .component.ts suffix and CartComponent class name are the older convention, still generated by old schematics
import { Component, ChangeDetectionStrategy, input, output, signal, computed } from '@angular/core';
import { CartRow } from './cart-row';

@Component({
  selector: 'app-cart',            // optional since v22: selectorless use needs only the import
  imports: [CartRow],
  template: `
    @let currency = 'EUR';
    <h2>{{ title() }} — {{ total() }} {{ currency }}</h2>

    @for (row of rows(); track row.id) {
      <CartRow [item]="row" (remove)="remove.emit(row.id)" />
    } @empty {
      <p>Cart is empty.</p>
    }

    @defer (on viewport; prefetch on idle) { <app-recommendations /> }
    @placeholder (minimum 300ms) { <div class="skel"></div> }
  `,
  // changeDetection defaults to OnPush since v22; Eager is the old "check always"
})
export class Cart {
  readonly title = input.required<string>();
  readonly rows  = input<Row[]>([]);
  readonly remove = output<number>();
  protected readonly total = computed(() => this.rows().reduce((s, r) => s + r.price, 0));
}

02Signals & reactivity

docs: signals
Writable signal
count = signal(0) — read count(), write count.set(1), count.update(c => c + 1), count.asReadonly()
Derived
double = computed(() => this.count() * 2) — lazy, memoised, glitch-free; never mutate state in here
Resettable derived
selected = linkedSignal(() => this.options()[0]) v20 stable — writable, but recomputes when the source changes; { set } option v22.1
Side effect
effect(() => history.replaceState(null, '', '?q=' + this.query())) — injection-context only (or pass { injector }); runs after change detection, cleans up with the component
Effect cleanup
effect((onCleanup) => { const t = setTimeout(...); onCleanup(() => clearTimeout(t)); })
Read without tracking
untracked(() => this.other()) — the standard escape hatch inside effect/computed
Equality
signal(obj, { equal: (a, b) => a.id === b.id }) — default is Object.is; mutating an object in place never notifies
Debounce a signal
q = debounced(this.raw, 300) v22 — time-shifted derivation without RxJS
RxJS bridge
toSignal(obs$, { initialValue: [] }) / toObservable(sig) from @angular/core/rxjs-interop v20 stable
Unsubscribe
obs$.pipe(takeUntilDestroyed()) v16 — replaces the destroy$ Subject + ngOnDestroy ritual
After render
afterNextRender(() => el.focus()), afterRenderEffect(() => …) v20 — browser-only, skipped on the server
Zoneless
provideZonelessChangeDetection() — default for new apps v21. Opt back in with provideZoneChangeDetection() + zone.js in polyfills
Force a check
inject(ChangeDetectorRef).markForCheck() — needed only when state changes outside signals (a third-party callback); a code smell in new code
// The whole reactive vocabulary in one component.
const query    = signal('');
const debouncedQuery = debounced(query, 300);                 // v22
const page     = signal(1);
const results  = httpResource<Hit[]>(() => ({                  // stable v22
  url: '/api/search',
  params: { q: debouncedQuery(), page: page() },
}), { defaultValue: [] });

const empty = computed(() => !results.isLoading() && results.value().length === 0);

effect(() => {                                                 // reacts to query only
  const q = query();
  untracked(() => analytics.track('search', { q, page: page() }));
});

03Component API surface

docs: components
Input
value = input(0) · id = input.required<string>() · n = input(0, { transform: numberAttribute, alias: 'count' }) v17.1
Output
saved = output<Order>() then this.saved.emit(o) v17.3 · from a stream: outputFromObservable(src$)
Two-way model
value = model<string>('') v17.2 — one declaration gives value + valueChange, readable and writable inside the child
Queries
ref = viewChild<ElementRef>('box') · viewChild.required() · viewChildren() · contentChild() · contentChildren() v19 — all signals, no static flag, readable in ngAfterViewInit or any effect
Lifecycle still used
ngOnInit (rare with signals), ngOnDestroy, ngAfterViewInit. ngOnChanges is not called for signal inputs — use computed/effect instead
Directive
@Directive({ selector: '[appHighlight]', host: { '(mouseenter)': 'on()' } }) — or selectorless v22
Pipe
@Pipe({ name: 'money' }) + transform(v: number): string — pure by default; pure: false runs on every CD pass, avoid
Built-in pipes
date, currency, number, percent, json, keyvalue, slice, async — import DatePipe etc. directly, not CommonModule
Dynamic component
<ng-container *ngComponentOutlet="cmp(); inputs: { id: id() }" /> or viewContainerRef.createComponent(Cmp)
Accessible primitives
@angular/aria v22 stable — headless, keyboard-complete Accordion, Combobox, Listbox, Menu, Select, Tabs, Toolbar, Tree; you supply every style
Animations
CSS transitions plus animate.enter / animate.leave v20 — the @angular/animations DSL (trigger/state/transition) is legacy and pulls extra bytes
Encapsulation
default emulated; ViewEncapsulation.ShadowDom or None. The old shadow-DOM CSS polyfills were removed v22

04Dependency injection

docs: dependency injection
Root service
@Service() export class CartStore {} v22 — replaces @Injectable({ providedIn: 'root' }); @Service({ autoProvided: false }) when you provide it yourself
Inject
private readonly http = inject(HttpClient); v14 — field initialiser or any injection context; constructor parameter injection still works but is not the style
Optional / hierarchy flags
inject(TOKEN, { optional: true }) · { self: true } · { skipSelf: true } · { host: true }
Lazy service
injectAsync(() => import('./pdf').then(m => m.PdfExporter)) v22 — keeps a heavy dependency out of the initial bundle; { prefetch: onIdle({ timeout: 1000 }) } warms it
Token
export const API = new InjectionToken<string>('API', { providedIn: 'root', factory: () => '/api' });
Provider shapes
{ provide: X, useClass: Y } · useValue · useFactory · useExisting · multi: true
Bootstrap providers
bootstrapApplication(App, { providers: [provideRouter(routes), provideHttpClient()] })
Scoped providers
component providers: [] (per instance) · route providers: [] (per activated route) · withExperimentalAutoCleanupInjectors() destroys route injectors on leave v22
Cleanup hook
inject(DestroyRef).onDestroy(() => sub.unsubscribe()) — works in services and functions, not just components
Run in a context
runInInjectionContext(injector, () => inject(Foo)) — the fix for "inject() must be called from an injection context" (NG0203)
// v22 idiom: a signal store service, root-provided, no NgModule anywhere.
@Service()
export class CartStore {
  private readonly http = inject(HttpClient);
  private readonly items = signal<Item[]>([]);

  readonly all   = this.items.asReadonly();
  readonly count = computed(() => this.all().length);

  add(i: Item) { this.items.update(list => [...list, i]); }
}

05Async data & HTTP

docs: HttpClient & resources
Provide the client
provideHttpClient(withInterceptors([auth])) — fetch is the default backend v22, and withFetch() was removed; use withXhr() only for upload progress edge cases
HTTP as a signal
user = httpResource<User>(() => `/api/users/${this.id()}`) v22 stable — re-fetches when the reactive URL changes, aborts the previous request
Resource state
value(), hasValue(), isLoading(), error(), status() ( 'idle' | 'loading' | 'resolved' | 'error' | 'local' ), reload(), set()/update() for local edits
Generic resource
resource({ params: () => this.id(), loader: ({ params, abortSignal }) => fetch(...) }) v22 stable
RxJS resource
rxResource({ params: () => this.id(), stream: ({ params }) => this.http.get(...) }) — when you need retry/switchMap operators around the load
One-shot call
await firstValueFrom(this.http.post<Order>('/api/orders', body)) — commands stay observables/promises; resources are for read state
Typed request options
this.http.get<T>(url, { params: { q }, headers, context, observe: 'response', responseType: 'json' })
Progress
{ reportDownloadProgress: true } / { reportUploadProgress: true } v22 — the single reportProgress flag is deprecated
Interceptor
const auth: HttpInterceptorFn = (req, next) => next(req.clone({ setHeaders: { Authorization: t } })); v15 — class interceptors need withInterceptorsFromDi()
Testing
provideHttpClientTesting() + HttpTestingController.expectOne(url).flush(body)
SSR cache
withHttpTransferCacheOptions({ includePostRequests: false }) — since v22 requests with cookies or withCredentials are excluded by default
// Read state as a resource; write with a plain call and reload.
@Component({ /* … */ })
export class UserPage {
  private readonly http = inject(HttpClient);
  readonly id = input.required<string>();

  readonly user = httpResource<User>(() => `/api/users/${this.id()}`);   // v22 stable

  async rename(name: string) {
    await firstValueFrom(this.http.patch(`/api/users/${this.id()}`, { name }));
    this.user.reload();
  }
}
// Template: @if (user.isLoading()) { … } @else if (user.error()) { … } @else { {{ user.value().name }} }

06Signal Forms

docs: forms with signals
Import
import { form, schema, FormField, required, email, validate } from '@angular/forms/signals'; v22 stable — a separate entry point from @angular/forms
Create
model = signal({ email: '', password: '' }); f = form(this.model, loginSchema); — your signal stays the source of truth; form() returns a FieldTree
Schema
const loginSchema = schema<Login>((p) => { required(p.email); email(p.email); minLength(p.password, 12); }); — reusable and composable, or inline as the 2nd argument to form()
Built-in validators
required, email, min, max, minLength, maxLength, pattern, validate, validateTree, validateHttp, validateStandardSchema (Zod/Valibot)
Cross-field
validate(p.confirm, ({ value, valueOf }) => value() === valueOf(p.password) ? null : { kind: 'mismatch' })
Field logic
disabled(p.delay, (ctx) => !ctx.valueOf(p.delayed)) · readonly(...) · hidden(...) — conditions live in the schema, not the template
Bind in the template
<form [formRoot]="f"><input [formField]="f.email" /></form> — the directive is FormField; in the v21 preview it was Field/[field], renamed in v22
Read state
f.email().value() · .errors() · .invalid() · .touched() · .dirty() · .disabled(); whole form: f().valid(), f().submitting()
Submit
form(model, schema, { submission: { action: async (f) => this.save(f().value()), ignoreValidators: 'none' } }) — a plain submit button triggers it; server errors map back onto fields
Arrays
applyEach(p.lines, (line) => required(line.qty)) — the model is a plain array; push/splice the signal value
State classes
provideSignalFormsConfig({ classes: { 'ng-invalid': f => f.state().invalid() } }) v22
Custom control
implement FormValueControl<T> (a value = model<T>() plus optional state inputs) — no ControlValueAccessor, no NG_VALUE_ACCESSOR provider
Legacy forms
ReactiveFormsModule with FormBuilder/FormGroup/FormControl is still supported and everywhere in existing code; FormsModule + [(ngModel)] is the template-driven ancestor. Neither is deprecated — but new work goes to Signal Forms
import { form, FormField, required, email, minLength, validate, validateHttp } from '@angular/forms/signals';

@Component({
  imports: [FormField],
  template: `
    <form [formRoot]="f">
      <input [formField]="f.email" type="email" />
      @if (f.email().touched() && f.email().invalid()) {
        <p class="err">{{ f.email().errors()[0].message }}</p>
      }
      <input [formField]="f.password" type="password" />
      <button type="submit" [disabled]="f().submitting()">Sign in</button>
    </form>
  `,
})
export class Login {
  private readonly model = signal({ email: '', password: '' });

  protected readonly f = form(this.model, (p) => {
    required(p.email, { message: 'Email is required' });
    email(p.email,    { message: 'Enter a valid email address' });
    minLength(p.password, 12);
    validateHttp(p.email, {
      request: ({ value }) => `/api/known?email=${value()}`,
      onSuccess: (r: { known: boolean }) => r.known ? null : { kind: 'unknown', message: 'No such account' },
    });
  }, {
    submission: { action: async (f) => this.auth.signIn(f().value()) },
  });
}

docs: server-side rendering

Hydration
provideClientHydration(withIncrementalHydration(), withEventReplay()) v19/v20 stable — without it the client destroys and re-renders the server DOM
Incremental hydration
@defer (hydrate on interaction) · hydrate on viewport · hydrate never — the block ships as static HTML until the trigger fires

10Idioms & gotchas

docs: best practices
  • Upgrading to v22 flips change detection. The migration writes ChangeDetectionStrategy.Eager into every existing component, so nothing breaks — but until you delete those lines you have not actually adopted OnPush.
  • Mutating an object in a signal notifies nobody. items().push(x) is a no-op for reactivity; use items.update(l => [...l, x]).
  • Calling a signal in a template is fine; calling a method is not. {{ total() }} memoises, {{ computeTotal() }} re-runs on every check.
  • effect() is not for deriving state. If the body only calls set(), it wants to be a computed or a linkedSignal.
  • NG0203 "inject() must be called from an injection context" — you called inject() inside a callback or after await; capture it in the field initialiser or wrap with runInInjectionContext.
  • NG0100 ExpressionChangedAfterItHasBeenChecked — dev-mode only, means state changed during rendering; with signals it usually points at an effect writing a template-read signal.
  • Zoneless surfaces missing notifications. Code that mutated fields from a setTimeout or a third-party callback silently stops updating; the fix is a signal, not markForCheck().
  • @for without a stable track destroys and rebuilds DOM on every change: lost focus, restarted animations, wrecked scroll position. Track an id, never $index for reorderable lists.
  • Signal inputs never fire ngOnChanges. Reacting to an input means computed, effect, or linkedSignal.
  • Route param changes reuse the component. Navigating /o/1 → /o/2 does not re-run the constructor; with input binding the signal simply changes, so derive from it rather than reading a snapshot.
  • Signal Forms come from @angular/forms/signals. Importing form from @angular/forms fails; and the v21 preview's [field] is [formField] since v22.
  • @defer only splits the bundle if the dependency is used nowhere else. One eager import of the same component elsewhere and the chunk collapses back into the main bundle.
  • SSR crashes on window/document. Guard with isPlatformBrowser or move the work into afterNextRender.
  • Hydration mismatches come from DOM the server did not produce: direct innerHTML writes, third-party widgets, invalid nesting like <p><div>. Wrap the offender with ngSkipHydration as a last resort.
  • providedIn: 'root' in a lazy chunk is still a singleton — but it lands in whichever chunk first imports it. For per-route state, provide on the route.
  • Interceptors registered both ways run twice. Pick withInterceptors([...]) or withInterceptorsFromDi(), not both.
  • Standalone means importing what the template uses. A missing DatePipe/RouterLink import is a compile error with strictTemplates, and a silently inert attribute without it.
  • Do not put an async pipe next to a signal read of the same source. Two subscriptions, two requests; convert once with toSignal.

Review heuristic. In a v22 codebase the three questions that find most problems: does this component still say Eager, does any state live outside a signal, and does every @for track a stable id?
