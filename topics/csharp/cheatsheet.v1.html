01Types & declarations

docs: types in C#
File-scoped namespace
namespace Acme.Billing; C# 10 — one per file, no braces, saves an indent level
Global using

Top-level statements
no Main: statements at file scope C# 9; args, await and return exit code all work

public record Money(decimal Amount, string Currency); C# 9 — value equality, with, Deconstruct, ToString

Target-typed new

File-local type
file sealed class Helper { } C# 11 — invisible outside the file; what source generators should emit

Alias any type

Enum with explicit base

// The 2026 default shape for a small domain type.
public readonly record struct Money(decimal Amount, string Currency)
{
    public static Money Zero(string ccy) => new(0m, ccy);
    public Money Add(Money other) => Currency == other.Currency
        ? this with { Amount = Amount + other.Amount }
        : throw new InvalidOperationException($"{Currency} != {other.Currency}");
}

// Primary constructor + required member: DI in, invariants enforced by the compiler.
public sealed class Invoice(IClock clock)
{
    public required string Number { get; init; }
    public DateTimeOffset Issued { get; } = clock.UtcNow;   // parameter captured once
}

02Members, properties & extensions

docs: classes, structs and members
field keyword
public string Email { get; set => field = value.Trim(); } C# 14 — compiler-synthesized backing field, no _email. Disambiguate a real member named field with @field or this.field
Lazy property, one line
public HttpClient Http => field ??= _factory.CreateClient(); C# 14
Extension block
extension(IEnumerable<T> src) { public bool IsEmpty => !src.Any(); } C# 14 — extension properties, static members and operators, not just methods
Static extension member
extension<T>(IEnumerable<T>) { public static IEnumerable<T> Identity => []; } C# 14 — called as IEnumerable<int>.Identity
Classic extension method
public static bool IsEmpty<T>(this IEnumerable<T> s) — still valid, still the only form that compiles below C# 14
Extension indexer
extension(IEnumerable<int> s) { public int this[int i] => s.ElementAt(i); } C# 15 — preview
Expression-bodied members
public decimal Total => _lines.Sum(l => l.Amount); — methods, properties, ctors, operators, finalizers
Partial member
partial methods C# 3, properties & indexers C# 13, constructors & events C# 14 — exactly one defining and one implementing declaration
User-defined compound assignment
public void operator +=(Vector other) { X += other.X; ... } C# 14 — mutates in place instead of allocating a new instance
Operator overload
public static Money operator +(Money a, Money b) => a.Add(b); — checked operator + for an overflow-throwing variant C# 11
Indexer
public Row this[int i] => _rows[i]; · public Row this[Index i] for ^1 support
Explicit interface impl
string IFormattable.ToString(string? f, IFormatProvider? p) => ... — hides the member unless cast to the interface
Default interface member
interface ILog { void Warn(string m) => Write(Level.Warn, m); } C# 8 — for versioning an interface, not for reuse; not visible on the class
Overload resolution priority
[OverloadResolutionPriority(1)] C# 13 — steer callers to the Span overload without a breaking change
Module initializer
[ModuleInitializer] internal static void Init() { } C# 9 — static, void, parameterless; runs before any code in the assembly
Caller info

Lambda parameter modifiers

Default lambda parameter
var add = (int x, int y = 1) => x + y; C# 12
// C# 14 extension block: properties, statics and operators, all on one receiver.
public static class SeqExtensions
{
    extension<T>(IEnumerable<T> source)
    {
        public bool IsEmpty => !source.Any();                       // extension property
        public IEnumerable<T> Tap(Action<T> f)                      // extension method
        {
            foreach (var x in source) { f(x); yield return x; }
        }
    }
}

// field keyword: validation and change notification with no hand-written backing field.
public sealed class Session
{
    public string Token
    {
        get;
        set => field = string.IsNullOrWhiteSpace(value)
            ? throw new ArgumentException("empty token", nameof(value))
            : value;
    }
}

03Pattern matching & switch

docs: patterns
Type pattern
if (o is Customer c && c.IsActive) ... C# 7
Constant / null
x is null, x is not null, x is 0 — is not null ignores an overloaded ==; prefer it in library code
Relational + logical
n switch { < 0 => "neg", 0 => "zero", > 0 and < 10 => "small", _ => "big" } C# 9
Property pattern
o is { Status: Status.Sent, Total.Amount: > 0 } — nested property access C# 10
Positional pattern
p is (0, var y) — needs a Deconstruct; records get one free
List pattern
arr is [1, 2, .. var rest] · arr is [_, _, ..] C# 11
Var pattern + guard
x switch { var v when v.Length > 3 => ... }
Discard
_ => throw new UnreachableException() — UnreachableException since .NET 7; better than a silent default
Switch expression
var fee = tier switch { Tier.Gold => 0m, Tier.Silver => 2m, _ => 5m }; C# 8 — non-exhaustive gives CS8509 and throws SwitchExpressionException at runtime
Switch on enum
exhaustiveness is not guaranteed: an enum can hold any underlying value, so always keep a _ arm
Closed-hierarchy switch
state switch { Closed => ..., Open(var pct) => ... } C# 15 — preview; with closed, no default arm and no warning
Labeled break/continue
outer: for (...) { for (...) { continue outer; } } C# 15 — preview; replaces the bool flag and the goto
Deconstruction
var (id, name) = customer; · (a, b) = (b, a); to swap
Tuple
(int Code, string Reason) Check() => (404, "missing"); — equality is element-wise; names are erased at runtime
// One switch expression replacing a nest of ifs — the shape reviewers expect in 2026.
static decimal Price(Order o) => o switch
{
    { Lines: [] }                                   => 0m,
    { Customer.Tier: Tier.Gold, Total: > 500m }     => o.Total * 0.85m,
    { Customer.Tier: Tier.Gold }                    => o.Total * 0.90m,
    { Lines: [var only] } when only.Qty > 100       => o.Total * 0.95m,
    _                                               => o.Total,
};

04Null handling

docs: nullable reference types
Enable NRT
<Nullable>enable</Nullable> in the csproj C# 8 — on by default in every dotnet new template since .NET 6
Null-conditional
customer?.Address?.City · list?[0] — short-circuits the whole chain
Null-conditional assignment
customer?.Order = GetCurrentOrder(); C# 14 — the right side is not evaluated when the left is null. ++/-- are still not allowed
Null-coalescing
var name = input ?? "anonymous"; · _cache ??= Build(); C# 8
Null-forgiving
_repo!.Save(x) — an assertion to the compiler, no runtime check. Every ! in a diff is a review question
Guard clause
ArgumentNullException.ThrowIfNull(order); .NET 6 — message uses the caller expression; no nameof needed
Other guards
ArgumentException.ThrowIfNullOrWhiteSpace(s) .NET 8 · ArgumentOutOfRangeException.ThrowIfNegative(n) .NET 8 · ObjectDisposedException.ThrowIf(_disposed, this) .NET 7
Flow attributes
[NotNullWhen(true)], [MaybeNullWhen(false)], [MemberNotNull(nameof(_x))], [NotNullIfNotNull(nameof(input))] — teach the analyser what a Try… method guarantees
Nullable value type
int? is Nullable<int>, a real runtime type. string? is only an annotation, erased to string at runtime
Pattern null test
if (o is not null) beats o != null when == is overloaded (records, test doubles)
Suppress per file/block
#nullable disable / #nullable restore — for staged migration of a legacy file, never as a permanent setting
Fail the build on it
<WarningsAsErrors>nullable</WarningsAsErrors> — the only way the annotations stay honest in a large team
JSON honours it
JsonSerializerOptions.RespectNullableAnnotations = true .NET 9 — deserializing null into a non-nullable member throws; on by default under Strict .NET 10
// Attributes are what make a TryGet usable under nullable analysis.
public bool TryGet(string key, [NotNullWhen(true)] out Session? session)
{
    session = _map.GetValueOrDefault(key);
    return session is not null;
}

if (TryGet(id, out var s))
    Console.WriteLine(s.Token);   // no warning, no `!`

06Strings, spans & perf

docs: memory and spans
Raw string literal
var json = """{"a": 1}"""; C# 11 — no escaping; the closing quotes' indentation is stripped from every line
Interpolated raw string
$$"""{ "id": {{id}} }""" C# 11 — $$ means {{ }} is the hole and single braces are literal
UTF-8 literal
ReadOnlySpan<byte> ok = "OK"u8; C# 11 — compile-time bytes, zero encoding at runtime
Comparison
string.Equals(a, b, StringComparison.Ordinal) for ids · OrdinalIgnoreCase for headers and keys · culture-sensitive only for display. CA1310 flags the culture-sensitive default
Numeric ordering
StringComparer.Create(culture, CompareOptions.NumericOrdering) .NET 10 — "Windows 8" sorts before "Windows 10"; not valid for IndexOf/StartsWith
Search many values fast
static readonly SearchValues<char> Delims = SearchValues.Create("&;="); .NET 8 then span.IndexOfAny(Delims)
Compiled regex
[GeneratedRegex(@"^\d{4}-\d{2}$")] private static partial Regex Ym(); .NET 7 — source-generated, AOT-safe, beats RegexOptions.Compiled
Slice without allocating
ReadOnlySpan<char> s = text.AsSpan(4, 8); — text[4..12] allocates a new string instead
First-class spans
T[] → Span<T> → ReadOnlySpan<T> implicit conversions now take part in extension-method receivers and generic inference C# 14
Stack buffer
Span<char> buf = stackalloc char[64]; — keep under ~1 KB and never inside a loop; use ArrayPool<T>.Shared.Rent above that
Build strings
string.Create(len, state, static (span, s) => ...) for an exact size · StringBuilder for unbounded · plain $"..." for the rest — the interpolated-string handler already avoids boxing C# 10
Parse / format
int.TryParse(s, CultureInfo.InvariantCulture, out var n) · IUtf8SpanFormattable.TryFormat .NET 8 for byte output
Hex / Base64
Convert.ToHexStringLower(bytes) .NET 9 · Convert.TryToHexString(utf8, dest, out n) .NET 10 · Base64Url .NET 9
Measure, don't guess
BenchmarkDotNet with [MemoryDiagnoser]; dotnet-counters for live GC and allocation rates. .NET 10's JIT adds array-interface devirtualization and stack allocation of small arrays, so some older micro-optimizations are now net losses
// Allocation-free scan of "key=value;key=value" using spans + SearchValues.
private static readonly SearchValues<char> Sep = SearchValues.Create("=;");

static void Parse(ReadOnlySpan<char> input, Action<string, string> onPair)
{
    foreach (Range part in input.Split(';'))            // Span.Split, .NET 9
    {
        var slice = input[part];
        var eq = slice.IndexOfAny(Sep);
        if (eq > 0) onPair(slice[..eq].ToString(), slice[(eq + 1)..].ToString());
    }
}

07Generics & generic math

docs: generic math
Constraints
where T : class · struct · notnull · unmanaged · new() · BaseType · IFace · T : U
allows ref struct
where T : allows ref struct C# 13 — lets a generic accept Span<T>; the anti-constraint that unblocked span-generic APIs
Static abstract member
interface IParser<T> { static abstract T Parse(string s); } C# 11 — the mechanism behind generic math
Generic math interfaces
INumber<T>, IAdditionOperators<,,>, IComparisonOperators<,,>, IBinaryInteger<T>, IFloatingPoint<T> .NET 7
Parse/format contracts
IParsable<T>, ISpanParsable<T>, ISpanFormattable, IUtf8SpanParsable<T> .NET 8 — implement these and your type drops into generic pipelines
Variance
out T covariant (IEnumerable<out T>) · in T contravariant (IComparer<in T>) — interfaces and delegates only, reference types only
default(T) vs null
default is 0 / null / a zeroed struct. Return default! or annotate [MaybeNull] when T is unconstrained
Type checks
typeof(T) · typeof(List<>) open generic · nameof(List<>) → "List" C# 14
Generic specialization
the JIT shares one body across all reference types and emits one per value type — why List<int> boxes nothing but many distinct structs grow code size
Static in a generic type
Cache<string>.Value and Cache<int>.Value are different fields — a handy per-type cache and a classic surprise
Generic helpers
EqualityComparer<T>.Default · Comparer<T>.Default · Unsafe.As<TFrom, TTo> — the last only behind a benchmark
Tensors
Tensor<T>, IReadOnlyTensor — no longer [Experimental] .NET 10, still shipped in the System.Numerics.Tensors package; arithmetic arrives via C# 14 extension operators
// One method, every numeric type — no overload per primitive, no boxing.
static T Sum<T>(ReadOnlySpan<T> values) where T : INumber<T>
{
    T total = T.Zero;
    foreach (var v in values) total += v;
    return total;
}

Sum<int>([1, 2, 3]);         // 6
Sum<decimal>([1.5m, 2.5m]);  // 4.0

08Async & concurrency

docs: asynchronous programming
Signature
public async Task<Order> GetAsync(int id, CancellationToken ct = default) — async void only for event handlers; anywhere else it is an unobservable crash
Return types
Task, Task<T>, ValueTask<T> (hot path, await exactly once), IAsyncEnumerable<T>
Concurrent awaits
var (a, b) = (await ta, await tb); after starting both · await Task.WhenAll(tasks) · await Task.WhenEach(tasks) .NET 9 to consume as they finish
Bounded parallelism
await Parallel.ForEachAsync(items, new ParallelOptions { MaxDegreeOfParallelism = 8, CancellationToken = ct }, WorkAsync); .NET 6
Cancellation
using var cts = CancellationTokenSource.CreateLinkedTokenSource(ct); · cts.CancelAfter(TimeSpan.FromSeconds(5)) · ct.ThrowIfCancellationRequested()
Timeout on any task
await task.WaitAsync(TimeSpan.FromSeconds(3), ct); .NET 6 — throws TimeoutException; replaces the Task.WhenAny + Task.Delay idiom
Library rule
.ConfigureAwait(false) on every await in library code. In ASP.NET Core there is no sync context, so app code can skip it
Async streams
async IAsyncEnumerable<T> ReadAsync([EnumeratorCancellation] CancellationToken ct) C# 8 — without the attribute, WithCancellation is silently ignored
Async disposal
await using var conn = ...; C# 8 — plain using on an IAsyncDisposable takes a blocking path or does nothing
Locks
System.Threading.Lock .NET 9 with lock (_gate) — faster than object and the compiler rejects await inside. For async, SemaphoreSlim(1, 1).WaitAsync(ct)
Interlocked / volatile
Interlocked.Increment(ref _count) · Interlocked.CompareExchange · Volatile.Read/Write — reach for these before a lock only in measured hot paths
Periodic work
using var timer = new PeriodicTimer(TimeSpan.FromSeconds(30)); while (await timer.WaitForNextTickAsync(ct)) { ... } .NET 6
Fire-and-forget
there is no safe fire-and-forget: hand work to a BackgroundService, a Channel<T> consumer or a queue. _ = DoAsync(); loses the exception
Never block
.Result, .Wait(), GetAwaiter().GetResult() — deadlock in any SynchronizationContext, thread-pool starvation in ASP.NET Core
Runtime async
.NET 11 moves the async state machine into the runtime for cleaner stack traces and lower overhead — preview today, no source changes needed

cts.CancelAfter(TimeSpan.FromSeconds(30));

    ids,
    new ParallelOptions { MaxDegreeOfParallelism = 8, CancellationToken = cts.Token },
    async (id, token) => await _client.FetchAsync(id, token));

10Idioms & gotchas

docs: code-quality rules
Struct equality
a plain struct without Equals/GetHashCode falls back to reflection-based comparison — slow and surprising. Use readonly record struct
Records are shallow
with copies references; a list inside a record is shared with the copy. Value equality on a record containing an array compares references
Primary constructor capture
a class primary-constructor parameter stays mutable and is captured into a hidden field per use — do not treat it as readonly, and assign it to a field when it matters
field shadowing
a type that already has a member named field changes meaning under C# 14 — disambiguate with @field or rename. Warning CS9258 flags it
Extension resolution
an instance member always beats an extension member; new extension properties do not override existing ones. Adding one to a widely-used type is a source-compat risk
Iterators are lazy
argument validation in a yield return method does not run until the first MoveNext. Split into a validating wrapper plus a private iterator
Closure over the loop variable
foreach captures per-iteration since C# 5, but a for loop variable is still shared — the classic "all lambdas print N"
IDisposable in DI
a captive dependency (singleton holding a scoped service) leaks for the process lifetime. ValidateScopes catches it in Development only
DateTime vs offsets
use DateTimeOffset for instants, DateOnly/TimeOnly .NET 6 for calendar values, and TimeProvider .NET 8 so tests can move the clock
decimal for money
double for currency is a defect, not a style choice. decimal is base-10, 28–29 significant digits
Enum is not closed
(Status)99 is a valid value. Validate at boundaries with Enum.IsDefined and always keep a _ arm
HttpClient lifetime
never new HttpClient() per request (socket exhaustion) and never one static instance forever (stale DNS). Use IHttpClientFactory
Culture leaks
ToString() and Parse default to the current culture. Set <InvariantGlobalization>true</> for services, or pass CultureInfo.InvariantCulture explicitly
Trimming & AOT
reflection-based serialization and DI registration break under trimming. Use the System.Text.Json source generator and set <IsAotCompatible>true</> to surface IL2xxx/IL3xxx warnings early
JSON duplicates
duplicate properties silently take the last value. JsonSerializerOptions.AllowDuplicateProperties = false .NET 10, or the Strict preset, turns that into a JsonException
Exceptions
catch (Exception ex) { throw; } preserves the stack; throw ex; destroys it. Never catch to log-and-swallow at a low level
ConfigureAwait everywhere
correct in a library, noise in an ASP.NET Core app (no sync context). Decide once per repo and enforce it with an analyser

12.NET 8 (LTS)2023-11-14Collection expressions and spread, primary constructors on classes and structs, alias any type, default lambda parameters, inline arrays, ref readonly parameters. LTS support ends Nov 2026: still the most common production baseline, and the one you will be asked to migrate.

Deprecated in practice: anything still targeting .NET Framework 4.8 is maintenance-only — .NET Framework gets security fixes, no new language features.

Cadence: a major runtime every November, alternating LTS (even, 3 years) and STS (odd, 2 years). Today .NET 10 (LTS), .NET 9 and .NET 8 are supported; .NET 8 and .NET 9 both end support in November 2026, so every project on either has a deadline this year.
