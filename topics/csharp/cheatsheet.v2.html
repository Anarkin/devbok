// The 2026 default shape for a small domain type: immutable, value-equal, allocation-free.
public readonly record struct Money(decimal Amount, string Currency)
{
    public static Money Zero(string ccy) => new(0m, ccy);
    public Money Add(Money o) => Currency == o.Currency
        ? this with { Amount = Amount + o.Amount }
        : throw new InvalidOperationException($"{Currency} != {o.Currency}");
}

{
    extension(string s)                                   // C# 14: instance extensions
    {
        public bool IsBlank => string.IsNullOrWhiteSpace(s);
        public string Truncate(int max) => s.Length <= max ? s : s[..max] + "…";

03Patterns & control flow

docs: patterns · jump statements
Type / declaration pattern
if (o is Order { Total: > 0 } order) … C# 7 — replaces as + null check; the variable is definitely assigned in the true branch
Switch expression
var fee = kind switch { "std" => 0m, "express" => 9.9m, _ => throw new ArgumentOutOfRangeException(nameof(kind)) }; C# 8 — CS8509 warns when not exhaustive
Property pattern
o is { Customer.Address.Country: "NL", Lines.Count: > 0 } C# 8; extended (dotted) form C# 10
Relational + logical
t is >= 0 and < 100 · c is not (' ' or '\t') · x is not null C# 9
Positional / tuple
p is (0, 0) · (a, b) switch { (> 0, > 0) => "I", _ => "…" } C# 8 — needs Deconstruct or a tuple
List & slice pattern
xs is [var first, .., var last] · args is ["--out", var path, .. var rest] C# 11 — arrays, lists, spans, anything countable and indexable
Constant / var / discard
is null, is 42, is "yes" (also on ReadOnlySpan<char> C# 11), is var x, _
Guard
case Order o when o.Total > 1000: · in expressions: Order { Total: > 1000 } => … is usually clearer
Exhaustive without default
a switch over a closed hierarchy or a union needs no _ arm C# 15 — today: a _ => throw new UnreachableException() arm (.NET 7)
Labeled break / continue
outer: for (…) { for (…) { if (hit) break outer; } } C# 15 — replaces the bool flag or goto; IDE0410 suggests it
Throw expression
_repo = repo ?? throw new ArgumentNullException(nameof(repo)); C# 7 — prefer ArgumentNullException.ThrowIfNull(repo) in a statement
Exception filter
catch (HttpRequestException e) when (e.StatusCode == HttpStatusCode.NotFound) C# 6 — stack is preserved; when (Log(e)) observes without catching
Rethrow
throw; keeps the stack; throw e; resets it; ExceptionDispatchInfo.Capture(e).Throw() rethrows from elsewhere
using declaration
using var conn = new SqlConnection(cs); C# 8 — disposed at end of scope; await using for IAsyncDisposable
goto case
goto case 1; — the only sane goto; switch sections never fall through without it
Legacy switch statement
switch (x) { case int n when n > 0: …; break; default: …; break; } C# 7 — still right when arms are statements with side effects
public static decimal Shipping(Order o) => o switch
{
    { Lines: [] }                                   => 0m,                       // list pattern
    { Total: >= 100m, Destination.Country: "NL" }   => 0m,                       // extended property + relational
    { Destination.Country: "NL" or "BE" or "LU" }   => 4.95m,                    // logical
    { Weight: > 20 } and { Express: true }          => 39m,
    (_, var weight) when weight > 20                => 19m,                      // positional + guard
    _                                               => 9.95m,
};

Enable

// Parse "key=value;key=value" without a single substring allocation.
static Dictionary<string, int> ParsePairs(ReadOnlySpan<char> input)
{
    Dictionary<string, int> result = [];
    var lookup = result.GetAlternateLookup<ReadOnlySpan<char>>();      // .NET 9
    foreach (var range in input.Split(';'))                             // .NET 9 span split
    {
        var pair = input[range].Trim();
        if (pair.IsEmpty) continue;
        int eq = pair.IndexOf('=');
        lookup[pair[..eq]] = int.Parse(pair[(eq + 1)..], CultureInfo.InvariantCulture);
    }
    return result;
}

the runtime implements await natively instead of the compiler state machine: cleaner stack traces, less overhead; on by default for net11.0 .NET 11 — no source changes
Legacy you will meet
APM BeginRead/EndRead → Task.Factory.FromAsync · EAP DownloadCompleted events · BackgroundWorker · raw new Thread(…) · ThreadPool.QueueUserWorkItem · ContinueWith chains → await
public async Task<IReadOnlyList<Quote>> GetQuotesAsync(IEnumerable<string> symbols, CancellationToken ct)
{
    using var timeout = CancellationTokenSource.CreateLinkedTokenSource(ct);
    timeout.CancelAfter(TimeSpan.FromSeconds(3));

    using var gate = new SemaphoreSlim(8);                          // bounded concurrency
    var tasks = symbols.Select(async s =>
    {
        await gate.WaitAsync(timeout.Token);
        try   { return await _client.GetQuoteAsync(s, timeout.Token); }
        finally { gate.Release(); }
    });
    return await Task.WhenAll(tasks);                               // one aggregate await, all exceptions observed
}

10Idioms & gotchas

docs: code-quality rules · coding conventions
Service shape
public sealed class OrderService(IOrderRepo repo, TimeProvider clock, ILogger<OrderService> log) C# 12 field-per-dependency + a 10-line constructor; either way, sealed by default and interfaces only where a second implementation exists
Guard then act
ArgumentNullException.ThrowIfNull(order); ArgumentOutOfRangeException.ThrowIfNegativeOrZero(qty); if (order == null) throw new ArgumentNullException("order"); — string names go stale, use nameof
Structured logging
[LoggerMessage(Level = LogLevel.Warning, Message = "Order {OrderId} retried {Count} times")] static partial void OrderRetried(ILogger log, int orderId, int count); .NET 6 log.LogWarning($"Order {id} …") — allocates, defeats filtering and breaks structured properties (CA2254)
Try-pattern
if (int.TryParse(s, CultureInfo.InvariantCulture, out var n)) · own APIs: bool TryGet(key, [NotNullWhen(true)] out T? value) try { int.Parse(s) } catch (FormatException) { … } — exceptions as control flow
Dispose
using var scope = _factory.CreateScope(); · own types: sealed + Dispose() only; the finalizer/Dispose(bool) pattern is for unmanaged handles, and SafeHandle replaces even that
HTTP
typed client via services.AddHttpClient<CatalogClient>() + IHttpClientFactory .NET Core 2.1 using var http = new HttpClient() per request — socket exhaustion; a single static HttpClient never refreshes DNS unless SocketsHttpHandler.PooledConnectionLifetime is set
Time
inject TimeProvider, call clock.GetUtcNow(); tests use FakeTimeProvider (Microsoft.Extensions.TimeProvider.Testing) .NET 8 DateTime.Now — local, ambiguous during DST, untestable
Equality
records for value semantics; structs implement IEquatable<T> (the default reflection-based ValueType.Equals boxes and is slow); never use a mutable object as a dictionary key
Enum handling
Enum.GetValues<Kind>() .NET 5 · Enum.TryParse<Kind>(s, ignoreCase: true, out var k) · Enum.IsDefined(k) — casts from int never validate; [JsonStringEnumConverter] for wire formats
Immutability
ImmutableArray<T> / FrozenDictionary for shared read-only state; IReadOnlyList<T> is a view, not a guarantee ((List<T>)view still mutates)
Source generators over reflection
[GeneratedRegex], JsonSerializerContext, [LoggerMessage], [LibraryImport] .NET 7 (over [DllImport]), config binder source gen .NET 8 — trim/AOT-safe, faster startup; dynamic and Activator.CreateInstance(Type.GetType(name)) are the AOT blockers

One-line pitfalls

  • Primary-constructor parameters are mutable captures: assign them to a readonly field if anything else might reassign them (IDE0290 hides this).
  • foreach loop variables are per-iteration since C# 5, but for (int i…) closures still share i.
  • list[i].X = 1 on a List<struct> does not compile; mutate through CollectionsMarshal.AsSpan(list)[i].X = 1 or use a class.
  • x.ToString(), double.Parse, string.Compare are culture-sensitive; use CultureInfo.InvariantCulture or StringComparison.Ordinal everywhere data is not for a human.
  • decimal for money; 0.1 + 0.2 != 0.3 in double; Math.Round is banker's rounding by default.
  • Integer arithmetic wraps silently; int.MaxValue + 1 is negative unless checked.
  • const is baked into callers at compile time — change it in a library and consumers keep the old value until they rebuild; use static readonly for anything that may change.
  • required is not enforced by default(T), Activator.CreateInstance or JSON deserialisation without [JsonRequired].
  • A ValueTask awaited twice, stored, or passed to WhenAll is undefined behaviour.
  • async void exceptions bypass every try; async Task methods that are never awaited leak exceptions silently.
  • lock (this), lock (typeof(X)) and lock ("str") lock on objects other code can also lock on; use a private Lock.
  • Static fields hold objects for the process lifetime; event subscriptions from long-lived publishers are the classic managed leak — unsubscribe or use weak patterns.
  • GetHashCode() of string is randomised per process: never persist it or use it for sharding.
  • Task.Run inside ASP.NET Core handlers costs a thread-pool thread for nothing; only offload genuinely CPU-bound work, ideally to a background service.
  • BinaryFormatter throws on every call since .NET 9 (removed from the shared framework); System.Drawing.Common is Windows-only since .NET 6.
  • Spans cannot cross an await or be captured by a lambda; slice into Memory<T> and call .Span at the last moment.
  • catch (Exception) that swallows is a bug; rethrow with throw;, or filter with when and let the rest propagate.
  • Interpolated strings in [Obsolete]/nameof contexts must be const: allowed since C# 10 only when every hole is a constant string.

Trim / AOT readiness in one line: set <IsAotCompatible>true</IsAotCompatible> on every library, treat IL2xxx/IL3xxx warnings as errors, replace reflection with generators, and dotnet publish -p:PublishAot=true in CI even if production ships JIT — the warnings are the point.
