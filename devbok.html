Developer's Body of Knowledge

    Generate more with Claude Code! ✨

    Everything shown here is generated by Claude Code from the prompts in prompts/. Open this folder in Claude Code (the desktop app, or claude in a terminal at the repo root) and use these slash commands:

    commandwhat it does
    /devbok-new [slug:] <topic> Registers a topic and generates version 1 of every kind, in parallel. The optional slug: prefix fixes the short name in the sidebar; the rest is the full topic text the prompts receive, so be as specific as you like. Examples: /devbok-new c#, /devbok-new dotnet: ASP.NET Core & .NET runtime (focus on the framework, not the language).
    /devbok-update <slug> [kind] Generates the next version of every kind, or of one kind. Older versions are kept and stay selectable in the version dropdown, so you can compare before and after a prompt change.
    /devbok-delete <slug> [<kind> v<N>] Deletes a whole topic, or one version of one kind. Version numbers are never reused.
    /devbok-list Lists the topics with the latest version per kind. A * marks an artifact whose prompt has changed since it was generated.

    When a command finishes, reload this page: the sidebar reads topics/index.js, which the commands regenerate. Deep links look like devbok.html#csharp/study/v2; leave the version off for the latest. Generation takes several minutes per topic (it researches the web first), so run one topic at a time.
