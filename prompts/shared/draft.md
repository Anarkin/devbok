## Draft mode — this is a dry run

Produce the complete page in miniature, so its layout and design can be checked in a couple of minutes:

- Exactly 2 units instead of the full set, each with one short paragraph, one code sample, one small table and two of whichever repeating block the brief asks for. Every other structural element the brief asks for (hero with chips, sidebar with scrollspy, anything between the hero and the first unit, the closing sections) is present, with one or two placeholder items each.
- Skip the web research entirely; use whatever version you already know and label it "(draft: unverified)".
- Do not open a browser. Keep the file under 40 KB. Add `--draft` to the validate command.
- Everything else in the brief applies unchanged — the design system in particular. A draft that breaks the design system is a failed draft.
